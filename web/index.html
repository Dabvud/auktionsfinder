    Zugang zu GitHub

    Zum Speichern von Suchen und für „Jetzt suchen“ braucht die App einen GitHub-Zugangsschlüssel. Er bleibt nur in diesem Browser.

    1. Auf github.com: Settings › Developer settings › Fine-grained tokens › Generate new token.
    2. Repository access: nur dieses Repo auswählen.
    3. Permissions: Contents und Actions jeweils auf „Read and write“.
    4. Schlüssel kopieren und hier einfügen.
